# Claim Rescue and Replacement v1

This directory preserves the frozen synthetic rescue/replacement evidence cited
in Section 9. The original failed propositions remain failed; these artifacts
evaluate narrower replacement propositions.

- `design-v1-failed.json`: retained first design iteration.
- `design-v2.json`: final frozen design.
- `confirmation.json`: untouched confirmation bound to the final design seed.
- `RESULTS.md`: human-readable result register and interpretation.
- `frontier-replacement-report.json`: frontier-all and selective-deep-work comparison.
- `integration-tests.jsonl`: group-authority, graph-publication, and rollback controls.
- `evaluation-contract-tests.jsonl`: priority and structured-ablation controls.
- `benchmarks.txt` and `graph-benchmark.txt`: local benchmark records.
- `frontier-replacement-dataset.json`: synthetic frontier fixture.

These files are implementation and mechanism evidence. They are not
independent replication, production load evidence, or controlled real-world
validation.
