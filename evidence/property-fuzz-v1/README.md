# Property Fuzzing Mechanism Evidence

Aggregate, non-private outputs from the contract-15 public-fact fuzzing audit in
the `eventframed` repository. Context relocation and constructed same-answer
paraphrase families passed the design simultaneous bound; unrelated semantic
bundle substitution did not. The smaller confirmation block retained the
ordering but did not give the positive families enough simultaneous support to
reach the frozen 0.90 requirement.

The artifacts report predictor sensitivity over a declared perturbation family.
They do not establish real-world interventions, causality, or autonomous
ontology discovery.

Source implementation and complete generated inputs:
