# Approximation and Prospective Inference Evidence

These are local, source-hashed correction records, not a published candidate
revision, untouched scientific confirmation or production validation. The
existing public development fixtures are deliberately reused for mechanism
checks; earlier failed quality gates remain unchanged.

The import script copies only explicitly listed synthetic/aggregate reports.
`provenance.json` and `SHA256SUMS` pin each imported file. `source-manifest.json`
pins the immutable control and local candidate source. Raw benchmark logs back
the generated timing summary. No private conversations or outcome ledger rows
are included. Synthetic fixture identifiers are test placeholders, not actual
session bindings or authenticated observations.

`audit.json` retains the measured 0.6982459966723692 maximum joint TV defect.
The conditional theorem and admission mechanism do not reduce it by themselves.
Numerical witness validity and historical-query weights remain open.

`inference-utility.json` separates prospective utility checks from retrospective
AP pilot planning. The 137-stream planning figure is not confidence-sequence
power or resolution of the historical AP effect. Its deterministic synthetic
sequence checks implementation, not empirical coverage under arbitrary laws.

`frame-benchmark-results.json` is the final-source extraction measurement.
`turn-fallback-audit.md` additionally preserves the pre-fix/intermediate record;
its historical failure labels do not describe the repaired final implementation.

Run `node scripts/import_approximation_inference.mjs /path/to/eventframed` from
the paper root only after software reports are final. Reimporting changes the
candidate evidence hashes and must not be called untouched replication.
