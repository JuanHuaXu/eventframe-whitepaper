# Observation-Learning Research Evidence

These selected follow-ups extend the early MMM observation pilots without
changing their failed historical verdicts. All imported files are byte-identical
to published Git blobs at reference-implementation commit
`7a7b9357c06ce855795b947ffcde2fd61a82d3ca`.

`provenance.json` maps each local filename to its original path and SHA-256.
`SHA256SUMS` covers the imported files and provenance map. Reimport requires a
local reference repository containing that commit:

```sh
node scripts/import_observation_research.mjs /path/to/reference-repository
```

No raw chat transcript, private session, model checkpoint, sealed outcome file,
or owned database is copied here. This is a selected evidence appendix, not a
redistribution of the entire research archive or a privacy certification.
Public retrieval relevance is not a truth or agent-success label.

| Evidence | Interpretation |
| --- | --- |
| Preserved v3 and retained v8 | Passed specific synthetic rescue screens; not universal adaptation |
| Member fitting breadth | Finite false-revocation coverage and speed pass; forecast-quality gate fails |
| Native v72 and v75 | Faster computation does not repair failed quality, harm and recovery gates |
| Protected v81 | Narrow development support/quality rescue; missing broader native controls |
| Log v82 and summary v83 | Numerical and prepared-cost components; approximation fidelity remains limited |
| SciFact calibration and NFCorpus transfer | Small ranking gains fail strict promotion; no actual-agent benefit established |
| Durable freshness | Finite future-writer service component; general mutations and agent integration remain open |
| Recurrent pilot | Tested configuration fails generalization/grokking; not a refutation of published grokking or HRM |
| Baseline selection | Adaptive accuracy reference and Full speed control on consumed development data |

The native control replication uses the previously consumed development seed,
40 worlds, three delay schedules, 120 cells per arm and 2,400 issued events per
cell. Repeating that cohort validates reproducibility, not independent scientific
confirmation. Timings are whole serial synthetic cores, not request tails.
Individual gates, intervals, counted units and limits remain in the source
reports. None of the seven whole research goals is marked complete.
