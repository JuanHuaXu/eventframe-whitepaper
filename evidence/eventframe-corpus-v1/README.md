# EventFrame Corpus Evidence

This directory contains privacy-reduced aggregate evidence for the contract-12
implementation in which canonical 5W1H EventFrame text supplies the semantic
corpus and raw transcript text remains opaque delivery metadata.

The earlier organic rank-adaptation reports under `evidence/rank-adaptation-v1/`
used full transcript text in semantic retrieval. They are retained as historical
false-start provenance but are superseded for current EventFrame-corpus claims.

No raw transcripts, prompts, answers, source identifiers, local paths,
databases, sockets, or session manifests are included here.
