# Drafts

Use this directory for working drafts before sections are promoted into `src/`.

Suggested convention:

- `notes_*.md` for rough formulation notes.
- `section_*.md` for section-level drafts.
- `review_*.md` for local scratch reviews that are not part of the formal `review/` pass.

Drafts may be incomplete, but they should still follow the repository rule that
the paper must not depend on private project history or prior conversations.
