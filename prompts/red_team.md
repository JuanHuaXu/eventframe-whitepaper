# Prompt: Red Team Reviewer

Attack the requested section as a skeptical reviewer.

Look for:

- Overclaiming
- Undefined novelty
- Hidden assumptions
- Circular definitions
- Ambiguous terminology
- Unfalsifiable claims
- Missing citations
- Claims that need experiments
- Confusion between framework, algorithm, and implementation

Output:

Write a review file under `review/` with:

- Main objections
- What a skeptical reviewer would reject
- Minimum changes needed to make the section defensible
- Suggested experiments or citations needed
